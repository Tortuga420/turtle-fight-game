# Turtle Fight Game

A fun multiplayer turtle fighting game built with HTML5 Canvas and Python. Players control colorful turtles, shoot projectiles, and use obstacles for cover in an arena-style battle.

## Features

- Colorful turtle characters with unique colors
- WASD movement controls
- Mouse-aimed projectile shooting
- Brick obstacles for tactical gameplay
- Health system with color-matched health bars
- Local multiplayer support

## Setup

1. Make sure you have Python 3.x installed on your system
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/turtle-fight-game.git
   cd turtle-fight-game
   ```
3. Start the server:
   ```bash
   python3 server.py
   ```
4. Open your web browser and navigate to:
   ```
   http://localhost:8000
   ```

## How to Play

1. Enter your name and select a turtle color
2. Use WASD keys to move your turtle
3. Move your mouse to aim
4. Click to shoot projectiles
5. Use the brick obstacles for cover
6. Try to hit other players while avoiding their shots

## Controls

- W: Move up
- A: Move left
- S: Move down
- D: Move right
- Mouse: Aim
- Click: Shoot

## Technologies Used

- HTML5 Canvas
- JavaScript
- Python (SimpleHTTPServer)
- SVG for turtle graphics
